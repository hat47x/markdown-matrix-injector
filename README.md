# Markdown Matrix Injector (MMI)

**コピーではなく、参照を。**

**Markdown Matrix Injector (MMI)** は、正本表データ（Excel / CSV / XML）をテキスト文書から**宣言的・読み取り専用・検証可能**に参照するための公開規約 **MMI Notation** と、その参照実装（VS Code 拡張）です。

```md
![[./設計データ.xlsx#状態遷移|A1:F20?header=first&caption=状態遷移表&id=tbl-state]]
```

AI エージェントがあらゆるファイルを編集できる時代、正本と文書内コピーの乖離（ドリフト）は人間の手作業時代より速く・大量に発生します。MMI はコピーを**参照**へ置き換え、構造的に書き込めない境界（Read-only MUST）で正本を守る——**人間と AI エージェントが共存する文書運用のガードレール**です。

## なぜ「規約」なのか

ツールは世代交代しますが、記法とその保証性質（読み取り専用・決定論・可視な劣化）は残ります。MMI Notation は conformance levels（L0–L3）で部分実装を許し、特定エディタ・特定 AI ツールに依存せず存続します（仕様書は Phase 12 で公開予定、決定正本: `01_Plans/adr/ADR-0012`）。同梱の VS Code 拡張は、その最上位 L3（Delivery Profile: エンタープライズ印刷制御・納品マニフェスト）に準拠する参照実装です。

## 主な特徴（提供価値）

1. **正本の完全性（恒久規範）**: 参照経路からは正本を改変できない（Read-only MUST）。「何でも編集できるエージェント」の時代の安全装置。
2. **ドキュメントのクエリエンジン**: 記法 `![[ファイル#シート|範囲?パラメータ]]` による宣言的な断面参照。巨大な正本から必要スライスだけを取り出すため、AI エージェントのコンテキスト経済にも適合。
3. **AI エージェントとの協働**: リンク切れ検知（Diagnostics）は機械検証可能な契約として、query-evidence 出力は「エージェントが書いた文書と正本の一致検証」の根拠として機能。
4. **Smart Fallback**: 巨大表のPDFレイアウト破綻を防ぐ「リンクカードUI」への自動縮退と、別紙の納品マニフェスト出力。
5. **脱Word・エンタープライズ印刷制御**: キャプション・相互参照・PDFの改ページ・Landscape（横向き）指定のサポート（実 PDF で再現実証済み）。
6. **開発者体験 (DX)**: オートコンプリートと静的解析（Diagnostics）による執筆支援。

## 開発の始め方

1. リポジトリをクローンし、`npm install` を実行します。
2. 実装コード、テスト、ビルド設定は [`03_Implement/`](03_Implement/README.md) 配下にあります。
3. 新規開発・修正を行う場合は、まず `01_Plans/issues/TEMPLATE.md` を用いてタスクの Issue Memo を起票してください。
4. AIエージェント（Codex等）を使用する場合は、必ず作業前に [`AGENTS.md`](AGENTS.md) を一読させてください。

## CI/CD

GitHub Actions による最小構成の CI/CD を同梱しています。

- **CI**: push / pull request ごとに `03_Implement` の build と unit test を実行します。
- **Release bundle**: タグ push または手動実行で、配布用 tar.gz アーティファクトを生成します。
