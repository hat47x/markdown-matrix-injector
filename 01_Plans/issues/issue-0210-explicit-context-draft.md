## 対象と起票根拠

[基本設計書キット](../../04_Documentation/kits/basic-design/基本設計書.md)の承認画面には、画面項目の表参照と「差し戻すときはコメントを必須とする」という条件節がある。表参照を別文書へ持ち出す際、利用者がこの条件節も明示的に選んで下書きに含められるようにする。表の内容やExcelの各セルの意味を今回の分析で確認済みとはしない。

この仕事は、既存の参照を挿して通常のMarkdownで一段落を添えるだけでも行える。専用の下書き支援がその操作より役立つかは未確認のため、Draftへ戻す。[併用執筆](issue-0211-vscode-excel-coauthoring-flow.md)を先に進め、繰返しの引用選択や出典修正に実際の負担が見つかった場合に再検討する。

残す設計要素は、主となる参照、人が選んだ条件節、原本へ戻れること、人の解釈と引用の区別である。華厳由来の部分・全体・役割の読みを文脈の省略へ、ニヤーヤ由来の適用点検を近傍注記の誤った転用へ当てる。用途・理由の専用入力を毎回要求する案は採用しない。

## 入出力と最初の境界

最初の主対象は、利用者が選んだ既存MMIの表参照一件とする。追加する文脈は、workspace内のMarkdownから人が指定した本文箇所に限る。操作は任意とし、参照だけを使う既存の執筆経路を継続できる。

採用する場合は、既存の参照作成・編集と、エディタで選んだMarkdown本文を使う任意操作を候補とする。別の作業票やCLIを標準の入口にしない。利用者が通常の本文として説明を加えられ、用途・関連付け理由の入力を確定の条件にしない。現在sourceと位置・引用を照合する処理は、原文の文字列と人の解釈を区別するために使い、意味的に必要な注記だと自動判断しない。

出力候補は、主参照、選んだ条件節、必要な引用元リンクを含む編集可能なMarkdownとする。source照合の内部基準や用途・理由の項目を、通常の本文へ一律に挿入しない。本文は人が選んだ範囲だけを含め、周辺章やブック値を暗黙に足さない。Linked参照を含むため、この出力だけでDetachedが成立したとは扱わない。

主参照の解決・検証には既存のparser・resolver・評価経路を使う。引用はデータとして出し、意図しないMMI参照やHTMLとして評価しない。下書きは明示操作で返し、引用元や既存の文書を自動更新しない。候補の自動推薦、意味的に十分な文脈の保証、公開Candidate schemaへの新しいkindの追加は初期範囲に含めない。

## 採用判断と実装候補

1. キットの参照と条件節を使い、通常の参照＋Markdown追記と、任意の引用支援による出力・操作を比べる。準備や修正が増えるだけなら採用しない。本文のどこを選び、どこから先を含めないかを明示する。
2. 既存参照の評価と、明示したMarkdown引用の照合をApplicationで組み合わせる。人が説明を添える場合は原文引用と区別し、同じ入力から同じ下書きを返す。
3. 有用な場面が確認できた場合に限り、VS Codeの既存参照作成・編集に任意操作として接続し、下書きの表示・修正・取消を確認する。新コマンドや共通処理は実際に必要な範囲へ限定する。
4. 同じ材料の二出力を試読し、適用条件の説明と、追記・修正のしやすさを確かめる。不要な注記が増える用途では、参照のみを選べることも確認する。

## Acceptance criteria

- [ ] 通常の参照＋Markdown追記と比べ、引用の選択や出典修正に役立つ具体的な場面を示す。用途・理由の必須入力や専用作業票を増やさない。
- [ ] 利用者が主参照と本文の選択範囲を明示し、付加を断っても通常の参照作成を続けられる。
- [ ] 現在sourceと引用位置・文字列を照合し、内容変更・不在・位置違いを表示する。引用の一致を意味関係の確認済みへ昇格させない。
- [ ] 下書きに、選んだ条件節と必要な原本への参照が残る。選んでいない近傍の注記、章本文、セル値を含めない。人が説明を添えた場合は原文引用と区別できる。
- [ ] 主参照の検証は既存のAuthority経路を使い、標準Markdownの下書きとして利用者が修正できる。引用元・既存文書・ledger・reviewの採否を自動変更しない。
- [ ] sourceの差替え後は現在の参照と引用を確認して再生成する。無関係なsource変更で既存Candidateの採否を一括失効させない。
- [ ] 試読者が「いつコメントが必要か」を出力から説明できるかを確認し、条件の読み落とし、不要な情報、準備と修正の負担を記録する。結果から採用範囲と有用度を判断する。

## Validation plan

次表はこれから作る検証材料である。Excel内の値の正しさ、実画面の入力挙動、文脈の自動検出の精度をこの試験の結果に含めない。

| 入力・操作 | 期待する結果 |
| --- | --- |
| キットの表参照と差戻し条件節を指定 | 参照と条件節が下書きに残り、それぞれ原本へ戻れる |
| 主参照のみを選択 | 従来の参照作成が成立し、条件入力を強制しない |
| 近くに無関係な注記を置く | 人が選んでいなければ含めない |
| 同じ文を別箇所に置く | 指定位置を確認し、同文があるだけで再束縛しない |
| 選択した本文の変更、位置変更、source不在 | 確認済みの古い引用として出さず、再選択を示す |
| 主参照のsource変更 | 既存の参照検証を通す。引用元だけの照合で成功としない |
| 引用内の参照記法・HTML | 引用として保持し、下書きの意図しない評価対象にしない |
| 別用途へ同じ表を再利用 | 通常の本文を修正できる。過去の関連付けを全用途へ自動適用しない |

単体では組み立てと選択範囲、結合では引用・主参照それぞれの検証とローカル入口を確認する。予定テスト名`explicitContextDraft.test.ts`は未作成であり、実装時に開発環境の手順で関連テストを実行する。

実機では選択、下書き表示、人による修正、取消を確認する。価値確認では参照のみの出力と条件節付きの出力を同じ資料で比べ、読者の説明と修正成果物を記録する。初めから工数削減率などの合格数値を置かず、誤読と追加の手間を見て採用範囲を決める。

## Remaining work

最初の作業は、通常の参照＋本文追記で残る負担を示すこと。有用な場面を確認するまで専用の入力schemaや新コマンドを実装しない。意味依存の自動推薦は後続探索に残す。実装・自動テスト・製品実機・利用価値の確認は未着手である。
