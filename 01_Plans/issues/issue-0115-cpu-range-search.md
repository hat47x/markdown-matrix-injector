## Execution Plan

### Proposed solution

### Acceptance criteria

- [x] Excelの領域・見出し・型・原本座標をローカル索引化し、mtimeによる差分更新・キャンセル・メモリ上限を扱う。全矩形の網羅生成を避ける。結合範囲は`!merges`から取り、空白セルから推定しない。
- [x] 索引がセル内容由来の情報を含むことを明示し、ローカル保存・明示した対象のみ・削除可能とする。
- [x] 自然言語を字句解析・構文解析し、中間表現・名前解決・意味検査を経て既存MMI文法へ変換する。中間表現を新しい公開記法にしない。
- [x] 未対応の集計・比較・否定・並べ替えを`grep`へ置換しない。`grep`は行全体の部分一致であり列単位の完全一致とは意味が違うことを検査で区別する。
- [x] ニューラル埋め込み・GPU・LLM・外部APIを必要とせず、文字特徴と辞書から問い合わせと領域の特徴を作る。
- [x] 完全一致索引、n-gram＋TF-IDF/BM25、疎ベクトル類似度、FlyHashを同じ特徴・データ・候補数・CPU条件で比較し、Recall@5／最上位正解率／棄却率／メモリ／cold-warm時間を記録する。
- [ ] 貼り付け断片の厳密照合をFlyHash等の近似検索に依存させない。候補の類似度を証明とせず原本と厳密照合する。曖昧なら選択させ、原本変更時は再検証する。
- [x] 自然言語60件以上の未見評価を行う。辞書調整用と評価用を分け、評価データで辞書を合わせ込まない。正解が存在する依頼のRecallと、該当なしを棄却する精度を分けて報告する。
- [x] 10/100/1000ブック、1千/1万/10万領域の段階で、初回読込・索引構築・差分更新・warm検索・厳密照合を別々にp50/p95とピークメモリで測る。CPU型番・RAM・OS・Node・seed・反復数を記録する。
- [x] 索引済みp95 100ms／検査込み300ms／Recall@5 95%以上は**採用目標**として評価し、未測定を達成済みにしない。届かない場合は候補数・対象規模・対応表現を見直し、LLMへ自動切替しない。
- [x] 誤った範囲の自動確定0、原本変更0、クラウド呼出し0を必須とし、FlyHashの採用・条件付き採用・見送りを根拠とともに決める。

## Remaining work

**結果（2026-09-24、詳細は[設計文書§7](../../02_Architecture/input-assistance-cpu-search.md#7-実測結果2026-09-24)）:** 実装は`03_Implement/src/search/`、評価は`03_Implement/scripts/cpu-search-eval/`、テストは`test/cpuSearch.test.ts`（27件）。

- 架空業務データ49領域: 領域検出49/49一致。未見の自然言語（独立作成・凍結して1回評価）のRecall@5はBM25/コサイン0.667（v1・v2とも）、FlyHash 0.667/0.633、完全一致0.600/0.533。調整用は0.963。**目標95%に未達。原因は検索方式ではなく限定文法の網羅不足**（4方式が同じ依頼で失敗）。
- 未見v2で、列に結び付いた条件が`grep`へ変換される安全上の不具合を1件検出し修正した。修正後は未対応15件がすべて棄却される。
- v2の失敗から一般規則（文の区切り、貼り付け先、口語の動詞、「Xが出てる」、関係節、構造名詞、括弧の限定語、実在する見出しの集計語）を足し、**未見v3（凍結して1回評価）でBM25のRecall@5が0.800**になった（言い換え0.500が残る最大の弱点）。未対応の誤受理は0件のまま。
- 合成データでの規模: 1万領域までは全方式がp95 11ms以下。10万領域ではBM25 157〜238ms・コサイン220〜269msが目標超過、FlyHashは33〜60msで目標内だがRecall@5が4〜7ポイント低い。10万領域のピークRSSは4.4GB（本環境の上限近く）。
- **FlyHash: 条件付き採用。** 既定はBM25。約5万領域を超えてBM25が時間目標を超える場合だけ、厳密な再順位付けを必須として候補の絞り込みに使う。貼り付け断片の照合と範囲の確定には使わない。

残り:

- 言い換え（表題・見出しに無い語で表を説明する依頼）への対応。改善は新しい未見セットで測る（v1〜v3は消費済み）。
- 該当なしの依頼で、既存の表に近いもの（例: 総合テストケース）が候補に出る問題（確定はしない）。
- Workerスレッドでの実行（現状は協調的な中断と進行表示のみ）。
