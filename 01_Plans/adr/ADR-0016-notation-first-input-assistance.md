# ADR-0016: 既定文法を中心とした入力支援と追加API課金を伴わないAI提案

- Status: Proposed
- Date: 2026-09-09
- Related: requirements.md Phase 5 / Phase 11、ADR-0012

## 背景

2026-09-09の依頼は、VS Codeで既定のMMI文法を滑らかに入力する支援と、余分なAPI費用がかからない生成AI支援の企画である。実機で既存のシート補完は動作したが、パラメータ値・既存参照編集・自然言語からの作成には改善余地がある。

## 提案する方針

1. 文法補完・選択式作成・既存編集・修正案内を基本機能とし、ネット接続もAI契約も必須にしない。
2. 既存規約と読み取り専用境界を維持する。新構文は追加しない。入力補助カタログは既存schema/パーサーと同期させる。
3. すべての入口を共通の参照編集モデル、検証、プレビュー、Markdownの最小範囲への適用へ接続する。
4. 生成AIは任意。ローカル専用推論を優先評価し、既存AIへの手動の依頼文受渡しも設ける。AI結果は検証前に適用しない。
5. 追加課金を保証できないLanguage Model APIによるクラウド呼出し、およびMMI独自の有料API接続は初期提供に含めない。既存契約枠の使用と無償を混同しない。
6. モデル不在・停止時も基本機能を継続する。自動再要求、モデルの自動取得、クラウドへの自動切替は行わない。

## 受け入れるトレードオフ

選択式案内には数段階の操作が必要だが、初心者が文法を覚える負担を減らす。熟練者向けの直接入力を維持する。ローカルモデルには端末資源と初回準備が必要であり、特定モデルの品質・必要メモリは評価後に決める。

## 状態と実行

本ADRは企画段階。コア仕様の変更・外部送信・新しい費用発生を承認するものではない。詳細な操作、現状との差、費用比較、計測条件は[企画書](../input-assistance-proposal.md)。実行はissue-0110→0111→0112→0113の順とし、同時に着手しない。
