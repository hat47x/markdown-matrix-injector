# 申請の状態遷移

Excelの「状態遷移」シートをMarkdown文書から参照する例です。申請の下書きから完了・再処理まで、12通りの状態遷移を一覧で確認します。

## 承認待ちに関係する遷移

![[./data/design.xlsx#状態遷移|A1:F13?header=first&grep=承認待ち&caption=表2　承認前後の確認]]

`grep=承認待ち`は、行の中に「承認待ち」という文字が含まれるものを表示する指定です。この例では5行が表示されます。

検索するのは「現在の状態」だけではありません。「次の状態」に「承認待ち」がある行にも一致するため、申請・再申請も結果に含まれます。

この表は状態遷移を確認するための表示です。厳密な状態条件は元のExcelで管理し、表示結果をそのまま自動の業務判定には使いません。
