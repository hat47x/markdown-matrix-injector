# 申請・承認システムで試すMMI

設計レビュー、試験確認、運用引継ぎ、納品準備に使える基本の12本と、CP932形式のCSVを参照する追加サンプル、納品用の体裁にする追加サンプルを1本ずつ用意しています。
**業務・データ・判定結果はすべて架空**です。各文書と`data`フォルダーを一緒に保管してください。

## 最初に開くファイル

VS CodeにMMIをインストールし、このフォルダーを開きます。
[01-first-table.md](01-first-table.md) を開いて `Ctrl+Shift+V` を押すと、4件の要件が表になります。
手順を詳しく知りたい方は [チュートリアル](../../tutorial.md) を参照してください。

## 元データの構成

基本の12本に含まれるCSVは9ファイル・合計172件（見出しを除く）です。要件24、状態遷移12、権限12、API10、障害12、リリース10、試験24、移行8、申請60を収録しています。13番目のCP932用CSVと、14番目の改訂履歴（`revisions.csv`）は、この集計とは別の追加サンプルです。
Excelの `design.xlsx` は状態遷移・権限・APIの3シート、計34件です。CSV版と比較するための同内容の別形式サンプルであり、業務で両方を正本にする運用は想定していません。
XMLは移行確認8件、TSVは設定4件です。MMIは表データを読み取り、これらを書き換えません。

## 自分の業務へ置き換えるには

1. 使いたい文書と`data`フォルダーを別の作業フォルダーへコピーします。
2. ExcelまたはCSVのどちらを正本とするか決めます。
3. 正本を普段使うツールで編集し、シート名・範囲・列をMarkdown側へ記述します。
4. プレビューを開き直して、対象IDと件数を確認します。
5. 納品時はMarkdown・別紙・必要なPDFを一緒に渡します。

`grep`は行内の部分一致検索です。集計、結合、承認判断、業務ルールの実行機能ではありません。
画像や結合セルなどのExcelレイアウトをそのまま貼り付ける機能でもありません。

## 検証と印刷

- 基本の12本の表示件数は [機械検証結果](../../media/release-20260908/sample-verification.json) と対応しています。CP932の追加サンプルはこの検証結果の対象外です。
- 実機の確認範囲は [リリース準備の検証記録](../../release-validation-2026-09-08.md) を参照してください。
- PDF化の手順は [利用マニュアル](../../user-manual.md#pdfを作る) にあります。
- 記法の正本は [MMI Notation v1](../../spec/mmi-notation-v1.md)、パラメータは [リファレンス](../../reference.md) を参照してください。

実機で作った [納品一覧CSV](08-release.delivery-manifest.csv) も同梱しています。自分の文書で作成する際は、ソースを開いて同じコマンドを実行してください。

## CP932のCSV

[CP932の日本語CSV例](13-cp932.md)では、Windows拡張文字・引用内カンマ・セル内改行を含む2件を表示する例を示しています。既存記録ではCP932対応VSIXの作成・インストールと自動テスト合格が記されていますが、VS Code画面での実機確認は未完了です。確認した環境と未確認事項は[CP932対応の検証記録](../../cp932-verification.md)を参照してください。
