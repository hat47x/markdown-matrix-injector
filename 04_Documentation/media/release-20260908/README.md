## 実際の操作を見る（60秒）

[納品一覧の生成とシート名補完の操作動画](mmi-live-walkthrough.mp4)

Windows版VS Codeで連続して録画した操作動画です。120秒の操作を2倍速に編集し、日本語字幕を付けています。音声はありません。

| 時間 | 内容 |
| --- | --- |
| 0–25秒 | Markdownを開き、コマンドパレットから納品一覧を出力 |
| 25–40秒 | 別紙2件のCSVを確認し、補完の練習ファイルを開く |
| 40–60秒 | Ctrl+SpaceでExcelのシート候補を表示し、状態遷移と範囲を入力 |

動画内の `_completion-check.md` は撮影用に作った練習ファイルです。手元で試す場合は、サンプルフォルダーに新しいMarkdownファイルを作り、`![[./data/design.xlsx#` まで入力します。候補を選んでから`|A1:F5?header=first]]`を続けると、4行の表になります。
