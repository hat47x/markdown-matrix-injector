## 2. パラメータ（12キー）

`params.schema.json`の`mode`・`header`・`columns`・`transpose`・`grep`・`highlightColumn`・`highlightValue`・`formatColumn`・`caption`・`id`・`pageBreak`・`orientation`をコアとする。

- 意味の固定: §6、§7、§8.1のケース。
- schemaと実装の一致: `conformance.test.ts`の「params.schema.json covers every query parameter」。
- 追加はminor、既存の意味変更はmajor。

## 4. 凍結前に決める残り

1. **P1**: corpus外の読み取り専用テストを、凍結の証拠としてどこに置くか（conformanceに含めるか、別の監査にするか）。
2. **P7**: i18n中立を規範として残すなら、キーがASCIIであることの試験を追加する。残さないなら規範から外す。
3. **P6**: §9の4コード以外の実装固有コード（`MMI_HEADERS_MISMATCH`等）はコアではない。コアの診断コードの一覧を§9に限定することを明記する。
4. **§10**: 劣化クラスを凍結するなら、CommonMark/Obsidian/L1の3クラスの試験を追加する。表示の見た目は凍結しない。
5. **L3 HTML契約**: クラス名・`data-*`属性を凍結する範囲を、参照実装の契約として明記する。
6. **`where=`**: コアに入れないことを確定し、予約キーとしての扱いを§11へ書く。
7. **Human Sponsorの承認**: ADR-0031を`Accepted`にし、仕様の`Version`を`1.0.0`へ上げる。
