# 基本設計書キット

Excelで管理する正本の表を、手で書き写さずに基本設計書から参照するためのひな形です。AIエージェントに執筆を任せる場合も、VS Codeを使って自分で書く場合も利用できます。例として扱うのは、架空の申請・承認システムです。

| ファイル | 内容 |
| --- | --- |
| [masters/基本設計.xlsx](masters/基本設計.xlsx) | 正本。機能一覧・画面項目・権限・状態遷移・メッセージの5シート |
| [基本設計書.md](基本設計書.md) | 見本。5章の本文と、正本への参照 |

## AIエージェントに書かせる

1. このフォルダーを案件のリポジトリへコピーし、`masters`にある正本を案件の内容に置き換えます。シート名と列は変更しても構いません。
2. [MMIのAI向け指示](../../../skills/mmi/SKILL.md)をAIに読ませます。Claude Codeなら`.claude/skills/mmi/SKILL.md`へ置き、GitHub Copilotなら`.github/copilot-instructions.md`へ、Codexなら`AGENTS.md`へ内容を貼ります。
3. Node.js 20以上の環境に配布版のMMI CLIを導入し、`mmi --help`が実行できることを確認します（[利用マニュアル](../../user-manual.md#コマンドで使う)）。開発用のチェックアウトを使う場合に限り、`03_Implement`で`npm run mmi -- <command>`を使います。
4. 依頼します。

```text
masters/基本設計.xlsx を正本として、基本設計書.md の「3. 権限設計」を書き直してください。
表は写さずにMMIで参照し、mmi check が通るまで直し、mmi render で本文と表が矛盾しないか確かめてください。
```

章を追加するときの依頼の例です。

```text
masters/基本設計.xlsx の「画面項目」シートを使って、基本設計書.md に承認画面（SC-04）の項目の節を追加してください。
必須項目と、差戻し時だけ必須になる項目を本文で説明してください。
```

AIエージェントは`mmi inspect`で正本の構造を調べ、参照を記述したうえで`mmi check`を使って検証します。表の値はAIエージェントが書き写すのではなく、正本のデータから描画します。

## VS Codeで自分で書く

MMI拡張を導入したVS Codeでこのフォルダーを開き、`基本設計書.md`をプレビュー（`Ctrl+Shift+V`）で表示します。参照の追加は、Excelで範囲をコピーして「MMI参照として貼り付け」を選ぶか、コマンドパレットの「参照を作成・編集」（`Ctrl+Alt+M`）を使います。参照の誤りは「問題」パネルに表示されます。

## 確認する

配布版のCLIを導入していれば、リポジトリの開発用依存パッケージを追加せずに、次のコマンドを実行します。

```sh
mmi check . --root .
mmi render 基本設計書.md --root .
```

`check`のエラーが0件で、`render`の各表に想定した行が表示されれば完成です。`grep`で絞り込む表では、検索語を含む列を`columns`で除外すると結果が空になるため、特に注意して確認します。

## 自分の案件へ置き換える

- 正本は一つのブックにまとめても、シートごとにファイルを分けても構いません。参照先のパスとシート名を合わせます。
- 件数や合計などの集計が必要なら、正本に集計用のシートを作り、その範囲を参照します。
- 列数が10を超える表やセル数が500を超える表は、別紙を参照するカードとして表示されます。本文に表示する行や列を絞るか、別紙として扱います。
