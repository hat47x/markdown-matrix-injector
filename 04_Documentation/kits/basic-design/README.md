# 基本設計書キット

基本設計書の表を、Excelの正本から写さずに参照するための型です。AIエージェントに依頼して書く場合も、VS Codeで自分で書く場合も使えます。題材は架空の申請・承認システムです。

| ファイル | 内容 |
| --- | --- |
| [masters/基本設計.xlsx](masters/基本設計.xlsx) | 正本。機能一覧・画面項目・権限・状態遷移・メッセージの5シート |
| [基本設計書.md](基本設計書.md) | 見本。5章の本文と、正本への参照 |

## AIエージェントに書かせる

1. このフォルダーを案件のリポジトリへコピーし、`masters`の正本を案件の内容に置き換えます。シート名と列は変えても構いません。
2. [MMIのAI向け指示](../../../skills/mmi/SKILL.md)をAIに読ませます。Claude Codeなら`.claude/skills/mmi/SKILL.md`へ置き、GitHub Copilotなら`.github/copilot-instructions.md`へ、Codexなら`AGENTS.md`へ内容を貼ります。
3. Node.js 20以上の環境へ配布されたMMI CLI tarballを導入し、`mmi --help`が実行できることを確認します（[利用マニュアル](../../user-manual.md#コマンドで使う)）。開発用checkoutを使う場合だけ、`03_Implement`で`npm run mmi -- <command>`を使います。
4. 依頼します。

```text
masters/基本設計.xlsx を正本として、基本設計書.md の「3. 権限設計」を書き直してください。
表は写さずにMMIで参照し、mmi check が通るまで直し、mmi render で本文と表が矛盾しないか確かめてください。
```

章を追加するときの依頼の例です。

```text
masters/基本設計.xlsx の「画面項目」シートを使って、基本設計書.md に承認画面（SC-04）の項目の節を追加してください。
必須項目と、差戻し時だけ必須になる項目を本文で説明してください。
```

AIは`mmi inspect`で正本の構造を確かめ、参照を書き、`mmi check`で検証します。表の値はAIが書かず、正本から描かれます。

## VS Codeで自分で書く

MMI拡張を入れたVS Codeでこのフォルダーを開き、`基本設計書.md`のプレビュー（`Ctrl+Shift+V`）を開きます。参照の追加は、Excelで範囲をコピーして「MMI参照として貼り付け」を選ぶか、コマンドパレットの「参照を作成・編集」（`Ctrl+Alt+M`）を使います。誤りは「問題」パネルに出ます。

## 確認する

配布CLIを導入した環境では、リポジトリの開発依存を入れずに次を実行します。

```sh
mmi check . --root .
mmi render 基本設計書.md --root .
```

`check`のエラーが0件で、`render`の各表に想定した行が出ていれば完成です。`grep`で絞る表は、絞り込みの語を含む列を`columns`で落とすと空になるので、特に確かめます。

## 自分の案件へ置き換える

- 正本は1冊にまとめても、シートごとにファイルを分けても構いません。参照のパスとシート名を合わせます。
- 集計（件数、合計）が必要な場合は、正本側に集計シートを作り、その範囲を参照します。
- 列が10を超える、またはセルが500を超える表は別紙カードになります。本文で見せる列と行に絞るか、別紙として扱います。
