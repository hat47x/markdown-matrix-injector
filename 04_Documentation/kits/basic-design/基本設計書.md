# 申請・承認システム 基本設計書（見本）

本書は架空の申請・承認システムの基本設計書である。表はすべて[masters/基本設計.xlsx](masters/基本設計.xlsx)を正本とし、本文には写さずMMIで参照する。正本を直すと、本書の表も次の表示から正本どおりになる。

## 1. 機能一覧

本システムは10の機能で構成する。各機能の画面と、対応する要件を表1-1に示す。

![[./masters/基本設計.xlsx#機能一覧|A1:F11?header=first&caption=表1-1　機能一覧&id=functions]]

## 2. 画面設計

### 2.1 申請入力画面（SC-03）

申請者は下書きを保存してから申請する。件名・申請種別・金額・申請理由を必須とし、申請IDと状態は表示のみとする。

![[./masters/基本設計.xlsx#画面項目|A1:G14?header=first&grep=SC-03&caption=表2-1　申請入力画面の項目]]

### 2.2 承認画面（SC-04）

承認者は判断に「承認」または「差戻し」を選ぶ。差し戻すときはコメントを必須とする。

![[./masters/基本設計.xlsx#画面項目|A1:G14?header=first&grep=SC-04&caption=表2-2　承認画面の項目]]

## 3. 権限設計

利用者は申請者・承認者・業務担当・監査担当の4つの役割に分かれる。操作ごとの可否を表3-1に示す。承認と差戻しができるのは承認者だけである。

![[./masters/基本設計.xlsx#権限|A1:F13?header=first&caption=表3-1　役割別の操作権限&id=permissions]]

## 4. 状態遷移

申請は「下書き」から始まり、承認後に業務担当が処理して「完了」となる。承認待ちの申請は、承認者が承認または差戻しし、申請者は承認前に限り取り下げられる。

![[./masters/基本設計.xlsx#状態遷移|A1:F13?header=first&caption=表4-1　申請の状態遷移&id=states]]

承認者が行う遷移だけを表4-2に抜き出す。

![[./masters/基本設計.xlsx#状態遷移|A1:F13?header=first&grep=承認者&caption=表4-2　承認者が行う遷移]]

## 5. メッセージ

画面に表示するメッセージを表5-1に示す。`{項目名}`などの波括弧は、表示時に置き換える。
