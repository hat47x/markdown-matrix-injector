# AIエージェントがMMIで設計書を書くための手引き（試作）

Claude Code、GitHub Copilot、CodexなどのAIエージェントが、MMIを使って設計書を書く際の手引きです。下の「エージェントへの指示」は、利用者のリポジトリにある`AGENTS.md`、`.github/copilot-instructions.md`、またはスキルに組み込むためのひな形です。既存の作業規則や正本の管理方針、機密情報の取り扱いを確認してから使用します。

コマンドライン版（CLI）は、Node.js 20以上で動くnpm互換の配布ファイル（tarball）として提供します。配布版を導入した環境では、`mmi <コマンド>`を使います。MMIリポジトリの開発用チェックアウトで作業する場合に限り、`03_Implement`で`npm run mmi -- <コマンド>`を代わりに使います。

## エージェントへの指示

以下の指示は、元のExcelなどを編集せずに参照を作り、候補と実際に確認した事実を区別するためのものです。候補が得られたことや、参照チェックでエラーが出なかったことだけで、業務内容の正しさが確定するわけではありません。

```markdown
## 表の扱い（MMI）

このリポジトリの設計書では、一覧表をExcelなどの正本から参照します。表の値を本文に写してはいけません。

1. Candidateを機械可読に扱う場合は、最初に`mmi schema candidate`で契約を取得する。
2. 正本の構造を調べる: `mmi inspect <ブック> --from <書く文書> --json`。出力の`candidateContract`が取得済みschemaの契約名と一致することを確認する。
   - シート、表（Excelテーブル名・表題・範囲）、列の見出し、行数、注意が返ります。
   - セルの値が必要なときだけ`--values 3`を付けます。
   - 検出したCandidateは参照先の**候補**です。ファイル・シート・表・範囲を確認してから採用し、提示された候補をそのまま正本の業務判断に読み替えません。
3. 参照を作る: `mmi select <ブック> --table <表名> --columns <見出し,見出し> [--contains <文字列> --in <見出し>] --from <書く文書>`
   - 標準出力の1行が参照です。そのまま文書に書きます。
   - 終了コードが1のときは、標準エラーの理由と候補を読んで指定を直します。
   - 「指定した列だけの絞り込みと一致しません」と出たら、表示する列か文字列を見直すか、その旨を本文に書きます。
4. 説明から探す: `mmi find "<表の説明>" --root <正本のフォルダ> --from <書く文書>`
   - 候補が複数あれば、どれを使ったかを本文で明らかにします。説明に似ているだけで参照先が決まるわけではないため、採用する前に正本の該当箇所と照合します。
5. 検証する: `mmi check <文書> --root <リポジトリのルート> --json`
   - エラーが0件になるまで参照を直します。診断コード（MMI_SHEET_NOT_FOUNDなど）は安定しています。
   - エラー0件は参照の診断結果であり、表の内容や本文の判断が業務上正しいことを保証しません。
   - 警告`MMI_PROSE_ID_NOT_IN_SOURCE`は、本文に書いたIDが、参照した表のどのセルにも無いことを示します。書き間違いか、正本の変更で消えたIDです。本文を直すか、正本に実在するか確かめてください。
6. 読み戻す: `mmi render <文書> --root <リポジトリのルート>`
   - 展開された表を読み、本文の主張（件数、区分、担当など）と矛盾しないか確かめます。正本を更新した後は、参照条件と本文の説明をもう一度確かめます。

守ること:
- 正本（Excel・CSV）を編集しない。
- 表の値を本文に写さない。本文で値に触れるときは、参照した表と矛盾しないことを render で確かめる。
- MMIの記法で表せない依頼（集計、比較、並べ替え、列を指定した完全一致）を、別の意味の指定（grepなど）に言い換えない。できないことは本文か依頼者への報告で明らかにする。
- inspect の出力を外部に送ってよいかは、組織の規則に従う。`render`が展開した表や`--values`で表示したセルの値にも、公開してよいとは限らない情報が含まれます。外部サービスへ送る場合は同じ基準で扱います。
- 人が確認していない候補やAIが推測した説明を、検証済み・承認済みと書かない。根拠が足りない場合は、未確認点として示す。
```

## 知っておくこと

MMIの参照は、元のファイルを読み取りながら表を表示する仕組みです。正本を更新した後も、参照している列・範囲と本文の説明が同じ意味を保つかを確かめてください。

- 列は見出しから選べます。ただし、参照記法にはExcelの列文字が記録されます。Excelに列を挿入すると、参照先が別の列へ変わることがあります。見出しによる指定を参照記法へ残すかどうかは、[ADR-0022](../01_Plans/adr/ADR-0022-semantic-selection-in-notation.md)で検討中です。
- Excelで非表示にした行や列、フィルターで隠した行も表示対象になります。`inspect`と`select`では、その点を注意事項として知らせます。
- Excelの名前付き範囲とテーブルは、名前から選べます。ただし、参照記法にはA1形式の範囲が記録されます。元の名前の定義を変更しても、参照範囲は自動では追従しません。
